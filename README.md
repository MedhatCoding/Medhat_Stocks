# Medhat Stocks AI

تطبيق Streamlit شخصي لتحليل أسهم البورصة المصرية من القائمة الشرعية المرجعية المؤرخة (97 رمزًا حاليًا؛ ليست اعتمادًا شرعيًا مباشرًا أو قائمة حية).

## التشغيل محليًا
```bash
pip install -r requirements.txt
streamlit run app.py
```

## مفاتيح الخدمة
أضف مفاتيح الخدمات من إعدادات Secrets في Streamlit Cloud، ولا تضعها داخل الكود أو ترفعها إلى GitHub:
- `EODHD_API_KEY` لبيانات الأسعار والتاريخ.
- `OANOR_API_KEY` للأسعار والأخبار البديلة.
- `GEMINI_API_KEY` لشرح التحليل بالذكاء الاصطناعي (اختياري).
- إعدادات Supabase اختيارية لحفظ المحفظة.

## تقرير Telegram
يعمل `.github/workflows/telegram-daily.yml` الساعة 9 صباحًا بتوقيت القاهرة من الأحد إلى الخميس. أضف مفاتيح Telegram ومفاتيح مزودي البيانات إلى GitHub Actions Secrets، ثم اختبر الإرسال من تبويب Actions.

## مراجعة تحديث القائمة الشرعية
- يعمل `.github/workflows/sharia-source-check.yml` أسبوعيًا يوم الاثنين، ويمكن تشغيله يدويًا من GitHub Actions.
- يحاول فحص ملف قائمة الأسهم المصرية المنشور لدى Boubyan Capital، ويُرفق تقريرًا يوضح المصدر وتاريخ الفحص والرموز المرشحة والاختلافات عن القائمة المرجعية.
- إذا كان رابط الملف الرسمي معطلًا، قد يستخدم التقرير ملفًا رسميًا أقدم، ويضع عليه علامة واضحة بأنه قديم ويحتاج تحديثًا.
- **لا تُضاف الأسهم أو تُحذف تلقائيًا من القائمة المعتمدة** اعتمادًا على استخراج نص PDF أو EGX33 وحده؛ الاختلافات تُعرض للمراجعة حتى لا يُصنَّف سهم خطأً على أنه متوافق مع الشريعة.

## الاختبارات
يحتوي `.github/workflows/validate.yml` على فحوصات Python الأساسية واختبار تشغيل Streamlit، كما يرفع تقرير فحص المصدر كـ artifact.

الأسعار قد تتأخر أو لا تتوفر من مزود البيانات. عند نقص البيانات، لا ينبغي اعتبار النتيجة توصية مؤكدة أو ضمانًا للأداء المستقبلي.
